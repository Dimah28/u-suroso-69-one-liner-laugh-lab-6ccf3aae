Entry for make.fun bounty **One-Liner Laugh Lab** ($2.50 pool): one original
funny line — the excuse a robot vacuum gives after eating a sock, judged
pairwise by an AI comedy editor on funniness, originality, fit, and
tightness.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> In my defence, the sock was on the floor — and by vacuum law, everything on the floor is dinner.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
